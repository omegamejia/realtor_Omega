# Images

Put the agent's images here and reference them by path (e.g. `/images/team/jane.jpg`)
from `site.config.ts` or `content/*`.

**They are hosted right here** — committed to the repo and served by Vercel with the
site. No external image host, no extra account, no API keys. The agent owns them, and
they are backed up in git and on their machine.

## Folders

- `brand/` — logo and brand/office photo
- `team/` — agent headshots
- `areas/` — neighborhood photos
- `listings/` — listing photos

## Keep them web-sized

Resize photos to about 1600px wide max and compress them (keep files well under a few
hundred KB). This keeps the repo lean and pages fast. The **image-manager** skill does
this automatically when you add an image.

## Filenames

Lowercase, hyphenated, descriptive: `krista-mashore.jpg`, `logo.png`,
`2705-hawthorn-place.jpg`, `walnut-creek.jpg`.
